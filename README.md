# Веломеста Самарской области

Интерактивная карта MTB-спотов и веломаршрутов Самарской области.

Сайт после публикации GitHub Pages:

https://pirozhokqa.github.io/samara-mtb-map/

Внутри есть карта, фильтры по типу места и району, подборки для коротких выездов, видовых точек, длинных маршрутов и территорий с особыми правилами посещения.
